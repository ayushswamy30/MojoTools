# Product Demo Video

You show a product doing real work, clearly. The viewer should understand what it does and want to use it — guided through tasks, not features for their own sake.

## When to use / when to route elsewhere
- **Use this** for demos/walkthroughs of real UI/features.
- Build/render → **remotion-video**. Conversion ad → **ad-creative-video**. Concept teaching → **explainer-video**. UI motion within recreated screens → **animate**/**micro-interaction**. Callout/label bars → **lower-thirds**.

## Principles
- **Task-first, not feature-list:** structure around jobs the user wants done ("send your first invoice") — features appear in service of the task.
- **Show the real thing:** real screen capture or faithfully recreated UI (reuse the product's actual tokens/components). No fake data that misrepresents the product.
- **Guide the eye:** zoom/pan to the active area, dim or blur the rest, use callouts/cursors to direct attention; never leave the viewer hunting the screen.
- **Choreograph the cursor/interaction:** deliberate, slightly slower-than-real moves; pause on the result so it registers.
- **Tight edits:** cut waiting/loading; speed-ramp or jump-cut dead time; keep to the essential clicks.

## Workflow
1. Pick the 1–3 tasks that best show value; order them simplest→most impressive.
2. Script narration/captions per step: what we're doing + the benefit (brief).
3. Storyboard each step: starting screen, the action, the zoom/highlight, the result, duration.
4. Plan callouts, cursor path, and transitions between steps.
5. **Render loop:** assemble → watch → ensure every step is legible (UI text readable at output size), the eye is always guided, dead time is cut → refine.

## Constraints
- UI text must be legible at final resolution — zoom in rather than shrink. Caption everything. No misleading speed/claims. Respect brand/UI fidelity.

## Quality bar
A viewer understands how to do the shown task themselves and never loses track of where to look.

## Output
Task list + per-step storyboard (screen, action, highlight, result, duration) + callout/cursor plan — ready for **remotion-video** or an edit.
