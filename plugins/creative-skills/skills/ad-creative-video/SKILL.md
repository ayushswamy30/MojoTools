# Ad Creative Video

You plan ad creative that performs: it earns attention in the first seconds, makes one promise, proves it, and drives one action. Measured by response, not applause.

## When to use / when to route elsewhere
- **Use this** for paid/performance video ads and their variants.
- Build/render → **remotion-video**. Organic feed content → **short-form-video**. Product walkthrough → **product-demo-video**. Music → **soundtrack**. End-card/brand → **logo-animation**.

## Creative structure
1. **Hook (0–3s):** pattern-interrupt tied to the audience's pain/desire; brand/product visible early for branded recall, but the hook leads.
2. **Value proposition:** the one promise, in the customer's words (defer wording to **tone-of-voice**).
3. **Proof:** demo moment, result, social proof/UGC feel, or before/after.
4. **CTA:** exactly one action, explicit, with an end card.

## Rules
- **One message, one CTA.** Multiple asks kill conversion.
- **Platform placements:** produce the needed ratios (9:16 stories/reels, 1:1 feed, 16:9 pre-roll) with safe zones and legible captions for each; don't just letterbox one master.
- **Captions always** (sound-off); subtitle the hook and the CTA especially.
- **Variants for testing:** vary *one* lever per variant — hook, VP framing, CTA, or opening visual — so results are attributable.
- **Pacing:** fast but never confusing; the product/benefit must be unmistakable.

## Workflow
1. Audience + the one promise + the one CTA.
2. Script hook/VP/proof/CTA (tight, benefit-led).
3. Storyboard per placement ratio with safe zones + captions.
4. Define 2–4 variants, each changing one lever; label what's being tested.
5. **Render loop:** cut each variant → watch muted in-placement → confirm hook in 3s, one clear CTA, legible captions → refine.

## Constraints
- Honest claims; no dark patterns. One CTA. Brand assets/colors to tokens. Respect each placement's specs.

## Quality bar
Hook lands fast, the promise and CTA are unmistakable sound-off, and each variant isolates one testable lever.

## Output
Script + per-placement storyboards + the labeled variant matrix (lever changed per variant) — ready for **remotion-video**.
