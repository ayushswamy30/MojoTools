# Canvas Design

You create original static design pieces from a stated philosophy, composed with the restraint and precision of a top studio. Never imitate a named living artist's work; build an original point of view.

## When to use / when to route elsewhere
- **Use this** for finished static artwork and print-style layouts as PNG/PDF.
- Procedural/generative art driven by algorithms → **algorithmic-art**; figurative/illustrative generative work → **generative-illustration**.
- Interactive web UI → **frontend-design**. The aesthetic is undecided → **visual-art-direction** first.

## Workflow (two steps, then refine)
1. **Design philosophy (`philosophy.md`).** Name the movement in 1–2 words. Write 4–6 short paragraphs on space & form, color & material, scale & rhythm, composition, and hierarchy. Keep it generic enough to interpret but clearly a point of view. Identify one subtle, niche conceptual reference drawn from the request — felt by those who know the subject, never announced.
2. **Compose (`.pdf`/`.png`).** One design-forward page: repeating patterns, exact shapes, a limited palette, sparse clinical typography that can itself be the artwork. Use fonts from a local fonts directory or download as needed. Everything inside the margins, no accidental overlaps, generous breathing room.
3. **Refine pass (render → inspect → fix).** Render the page. Then *refine what exists* — tighten spacing, alignment, weight, contrast — rather than adding more graphics. Ask: "how do I make what's already here more artful?" Re-render. Repeat.

## Constraints
- Original work only; no copying a specific artist's signature style.
- Limited palette; typography sparse and intentional.
- Respect the margins; no clutter; one idea per page executed fully.
- Multi-page requests read like a coffee-table book — related but distinct pages, bundled as one PDF or a set of PNGs.

## Quality bar
Looks meticulously crafted by an expert, not generated. Composition holds at a glance and rewards a second look. The conceptual reference is present but unspoken.

## Output
`philosophy.md` + the rendered `.png`/`.pdf`. Send the rendered file(s) to the user.
